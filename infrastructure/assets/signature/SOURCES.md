# Signature icons

Images Sealwax sends inside a designed HTML signature (issue #6), each drawn in one grey
(`#8a8a8a`), readable on light and dark mail. The PNG files are rendered from the SVG files
beside them with `rsvg-convert -w 48 -h 48`.

- `place`, `phone`, `mail`, `web`: drawn for Sealwax.
- `linkedin`, `x`, `github`, `instagram`, `facebook`, `youtube`: [Simple Icons](https://simpleicons.org/)
  9.21.0 (`icons/<name>.svg`), CC0 1.0, recoloured. The brands are their owners' trademarks; a
  signature shows them only to link to the user's own profile.
